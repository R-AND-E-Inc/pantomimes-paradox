## What changed

New process stage paragraphs provide conditional reuse, diagnosis, interface, full-review-range and
continuation recipes; the existing stages remain the owners. Activation and import selection are
clarified in adoption. Templates add conditional fields; projects with established owners use those
owners rather than adopting duplicate records. No public skill or lifecycle gate was added.

The package adds isolated behavior fixtures and documentation, a deterministic package inventory,
local tag/source/export alignment, and catalog-derived text scan coverage. The runtime resolver's
schema and read-only responsibility are unchanged apart from bootstrap selection of the new release.

Package identity covers supporting files as well as pinned payloads; it does not expand an existing
project's process hash. Chat exports carry only their declared payload and loader, not the complete
library/templates. Their receipt identifies the complete source inventory without claiming those
support files are in each archive. Local release checks do not establish remote publication or client
invocation. Behavioral observations and installed-client receipts are reported separately.

## Evidence

`tests/behavior/README.md` defines the cohort and assessment method. The release evidence record reports
actual runs, failures, unavailable clients and limitations; a fixture or planned case is not a pass.
No claimed benchmark savings from the reviewed repositories are carried into this release.
